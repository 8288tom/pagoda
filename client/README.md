# Client

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```
While developing, backend should run on localhost:4000, state automatically updates the URL to Dev URL.
SSO flow is automatically disabled in Development.

### Lints and fixes files
```
npm run lint
```


### Deployment

Once commits have been pushed Amplify automatically deploys the relevant branch.
